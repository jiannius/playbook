# Working on playbook

## After every release, draft a WhatsApp to the team

When a playbook release is published (a `vX.Y.Z` tag with its GitHub release), draft a WhatsApp
message to the team with the `jiannius-whatsapp` skill.

**Who:** everyone in that skill's team directory (its roster of aliases), except the person
sending it. Take the roster from the skill each time rather than from a list here, so a new
teammate is included once they are in the directory.

**How:** the skill's own rules apply. It is one recipient per confirmation, with no broadcast:
show each teammate's draft and send it only when TJ confirms.

**What to say:** a few short lines in plain words:

- The version, and in one or two sentences what changed for them.
- What they have to do, taken from the release's **Upgrading** section: nothing, run
  `boost:update`, raise the constraint, or restart Claude Code. Say "nothing to do" when that's
  true.
- The release link.

Skip a release only when TJ says so.
